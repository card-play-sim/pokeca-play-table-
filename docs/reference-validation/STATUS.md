# 固定120枚・参照版の効果検証（2026-11-09）

正式採用版の確定は0/120枚のまま。名称のみの固定デッキJSONを変更せず、45種類の既存プレビューと同じ印刷版を「効果検証用参照版」として別フィールドに保持する。元の1945件ZIP、29抽出ファイル、画像台帳、既存証跡および従来5件のEffect Command資料は変更していない。

## 修正と検証

- サイド取得と後続バトル場選択が同時に保留されたとき、AIはサイド取得を完了してから後続の選択権を渡す。保存・復元を挟む回帰検査も合格。
- ハンディサーキュレーターはダメージ・攻撃効果の後、きぜつ・サイド・後続選択の前に、守備側が元の攻撃ポケモンの物理エネルギーを選択する。攻撃側が手札に戻った場合に交代後のポケモンから移さない（公式FAQ保存済み）。きぜつを伴う処理順序も検査。
- 進化ポケモンのきぜつで、進化元の名称を進化後の名称へ書き換えた状態でトラッシュへ置いていた不具合を修正。物理カードと印刷版を分離して保持し、研究履歴を含む復元が合格。
- 実アプリで攻撃後に自動的に番が移る場合もAI応答を開始。未接続効果の停止は対戦ID単位で保持し、再読込後にも継続。
- 89印刷版の公式テキストを印刷版ID・セット・番号・出典SHAへ結合。既定45参照版の既知効果を既存ゲートウェイへ接続。未知の別印刷版テキストは実行を拒否。元の採用版確認ゲートは保持。
