# 特殊進化接続契約 v0.1（実装前・未承認）
更新日: 2026-11-07
対象: 公開架空カード試験版の進化処理と、将来の承認済み Effect Command 接続
状態: SPEC_ONLY / EFFECT_EVOLUTION_BLOCKED

## 現状確認
- 公開 ui/engine.bundle.js の通常進化は action.type='evolve' により進化元 species/evolvesFrom、stage差1、登場ターン・同一ターン進化禁止等を判定する。
- 公開 bundle 内に独立した特殊進化 Command は確認できない。
- この契約は正式1945件DB、固定2デッキ45種類、Rule Engine v0.1.2、Effect Integration v0.1 を変更しない。

## 分離する処理経路
1. NORMAL_EVOLUTION: 手札からの通常進化。既存 evolve の合法性判定を維持。例外フラグをユーザー入力から受け取らない。
2. EFFECT_EVOLUTION: 公式原文から承認済み解析を経た効果のみが発行可能。通常 evolve を使い回して制限を一律解除しない。
3. 未承認または未対応の効果は BLOCKED とし、盤面・手札・山札・トラッシュを変更しない。

## EFFECT_EVOLUTION に必要な契約（未定義のまま）
- 発生元: カード instanceId / officialCardId / 効果識別子 / 証跡
- 起動: グッズ、サポート、スタジアム、特性、ワザ等の合法な効果解決
- 対象: 所有者、対象ポケモン instanceId、場所、対象選択条件
- 進化先: 取得元ゾーン、カード識別、選択可能範囲
- 例外: 登場ターン制限、同一ターン進化制限、進化段階、進化元、その他のうち公式効果が明示的に変更する条件のみ
- 解決順序: 対象確認→効果条件確認→カード移動と進化→派生値再計算→状態ベース処理→履歴→atomic commit
- 失敗: 条件不成立・対象不正・証跡不足・未実装 Command は全変更をロールバック
- 監査: 発生元・適用した例外・前後 stateId/version を記録

## 必須検証
- たね→1進化、1進化→2進化は通常条件を満たす場合のみ成功
- たね→2進化、登場ターン進化、同一ターン連続進化は通常経路では失敗
- 特殊効果が進化ターンだけを変更する場合、進化段階は勝手に変更しない
- 特殊効果が段階を変更する場合、進化ターン制限も勝手に変更しない
- グッズ・サポート・スタジアム・特性・ワザの効果起動条件をそれぞれ保持
- 不明な公式ID、未承認解析、任意の bypass フラグでは成功しない
- 失敗時に手札・山札・進化元・HP・付属カード・履歴・サイドを変更しない
- 既存保存対戦の復元互換性を維持

## 実装開始のゲート
承認済みのカード効果原本と Effect Command 契約に、対象・移動・例外条件が揃うまで EFFECT_EVOLUTION は未実装のままにする。カード名や効果内容を推測して埋めない。通常進化の stage ガードを外さない。
