# 固定デッキのAI対戦入口 v240

画面上部の「固定デッキ対戦」→「この固定デッキでAI対戦を開始（検証用）」→確認で、既存の参照版効果検証対戦へ接続する。自分はガルーラ4・ファイアロー2・ニューラ2型60枚、AIはドラパルトex型60枚。正式採用版の確定は0/120枚のまま。画像は公式証跡のある暫定プレビューであり、正式対戦の合格を意味しない。

架空カードの対戦はメニューの「開発用：架空カードのAI試験対戦」に残した。従来の検証メニューのデッキ入替、画像確認盤面、操作練習も保持。新しいエンジンや効果・IDは追加していない。未接続効果は既存の停止画面でカード・効果・不足理由を表示する。

固定デッキの検査中に発見した、後続/対象選択ダイアログが前の非表示DOMに遮られる問題をUIで修正。サイド取得・対象選択を終えても次の選択が残る場合、次のダイアログを表示する。

正式DB・固定デッキJSON・画像台帳・既存証跡・対戦エンジンは変更していない。PWAキャッシュと全アセット参照をv240へ更新。

検査方法：Chromium Pixel 5 Android Chrome相当。新しい画面上部の入口をタップし、両者各60枚の名称別枚数と参照情報を原本JSONに照合。実アプリのAI自動応答を使用し、人側は合法操作と実タッチのベンチ配置を行う。構成120枚・手札・バトル場・ベンチ・トラッシュの画像デコード、ターン更新、選択ダイアログ、終局と再読込後の完全復元を検査。物理Android端末は今回の開発環境では未検査。

開発用の架空カード対戦も2戦終局・復元合格（27/19ターン）。これは固定デッキの合格には流用しない。

実行：`CHROMIUM_EXECUTABLE=/usr/bin/chromium python tests/test_reference_match_browser.py`。公開版には `POKECA_TEST_URL=https://card-play-sim.github.io/pokeca-play-table-/` を指定。旧架空カードの検査は `tests/test_published_ai_browser.py`。全オフライン回帰は `node scripts/run-offline-tests.cjs`。

ローカル最終結果：固定デッキ2戦が11/33ターンで終局。タッチによるベンチ配置2/6回、選択ダイアログ1/6回、構成プレビュー120/120枚、初期手札・場の画像各7件、終局時の場・手札画像15/14件、トラッシュ画像5/30件を確認。両戦とも保存・再読込一致、JS例外なし。全オフラインNode回帰（既存AI8戦・参照版AI2戦・効果41検査等）合格。画像解決・保存キュー・89印刷版証跡・Pythonヘッダ4件と表示配線6件も合格。
