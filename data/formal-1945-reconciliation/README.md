# 軽量原本による固定120枚・45種類の再照合

## 結果

- 入力：`pokeca_1945_codex_evidence_slim.zip`。29ファイルのCRC、マニフェスト28件のサイズ/SHA-256、1940カードと画像・台帳の結合、1945参照のJSON/JSONL一致を検証。
- 原本内では13種類・57印刷版が一致（固定デッキ29枚分の名前）。1940件はたねポケモンのカードデータ、5件は識別専用メタデータであり、1945件すべてが対戦用カードデータという意味ではない。
- 原本未収録の32種類を公式検索で追加調査。既知ページを再利用し、必要な追加17検索だけを取得。781候補IDを列挙したが、採用版は選択していない。分類証跡として各名の先頭の完全一致候補を1件ずつ詳細照合した。これは採用版の選択ではない。
- 追加27種類の公式詳細はID・名前・set・番号・画像URLが一致。基本エネルギー3種類は確認した2印刷版ずつで番号欄が空のため、厳格な登録条件を緩めず保留した。
- 57＋27＝84印刷版を既存の証跡インポーターで1件ずつ保存・再読込・検証。63参照を追加し、既存30参照とその原27件の全フィールドを保持。現在の参照台帳は93件。
- 候補画像は84/84版の実デコード・描画を確認。中断前の57版は記録ハッシュ不変を確認して結果を引継ぎ、未完了27版のみ追加検査した。候補画像の描画はデッキへの版採用でも利用許諾の承認でもない。
- 固定120枚：採用版確定0枚、未確定120枚、確定版の表示0枚。既存一覧の候補プレビューは59枚分を実表示。完成判定はBLOCKED。

## 原本と証跡の扱い

軽量ZIP SHA-256：`d1ec033f245d84e9d1e12eeb2b60b537051109608100d81183d3f4f2c14c9ab2`。カード原本：`6a6ba0837d3fc3392bfc41537d6666c19719ab554921d4e64fdb1bbbb615a790`、画像参照台帳：`0a9746f8084a1569ce149a2616e9c5086c72951b1eed2b1bed430f842a89831f`。

原本ZIPと展開した29ファイルは読み取り専用で扱った。原本を編集・再生成せず、添付された説明文や役割指示を作業指示として実行していない。原本の権利・simulator.renderAllowed等の保留フラグは派生証跡にも保持し、対戦エンジンや固定デッキの識別フラグを変更していない。画像本体・スクリーンショットを保存/再配布していない。

CODEX_SLIM_MANIFESTの28件を現在のバイト一致検査に用い、最新のpromotion_1943_to1945_validationと実レコード数を照合した。DELIVERY_MANIFESTや1469/1118件時点の古い監査は履歴として区別し、現在1945件の検査結果へ置き換えたり原本を書き換えたりしていない。生HTMLと一部の元入力/完了receiptは軽量ZIPに含まれないため、全6172ファイルを回収したとは扱わない。

- `たけしのスカウト`の完全一致は得られず、`タケシのスカウト`では3候補。`ロケット団のエネルギー`の完全一致は得られず、`ロケット団エネルギー`では3候補。正式名称の訂正根拠と対象版の指定が必要であり、自動改名していない。
- 基本悪・超・炎エネルギーは、初回に見たM6aと追加確認したMCの公式詳細ページにset表示はあるが番号欄が空。画像ファイル名からカード番号を作らずPRINT_EMPTYとして保存。

## 再現と検査

原本検証・抽出：`python tools/reconcile_formal_zip.py source.zip data/fixed-test-decks.json output-dir`。既存登録アダプター：`scripts/register-formal-image-candidates.cjs`。正式候補と追加公式HTML証跡で同じID/name/set/number/URL照合・原子的保存を使う。既存のwriter lockを共有し、競合・改ざん・版不一致は停止する。

テスト：ZIP破損/ハッシュ不一致、カード・画像・台帳の結合矛盾、metadata-only区分、原本不変、57件の1件保存、再実行、版衝突、追加HTML改ざん、writer lock、既存画像/対戦回帰を検証。実画像検査はChromium Pixel 5相当でHTTP 200/image、decode、寸法、contain、可視描画、GameState不変を確認。実機Androidは未検証。

GitHub上では全DBを再配布せず、固定デッキに関する派生候補・入力ハッシュ・監査だけを保持する。完了済みの公式収集を再実行しないため、この引渡しコミットは[skip ci]とし、ローカルで必要な検査を完了している。
