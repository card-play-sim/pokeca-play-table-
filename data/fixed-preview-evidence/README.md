# 第5段階：固定120枚の暫定画像表示

A：120/120枚を実画像で表示。B：正式採用版確定0/120枚。C：画像未表示0枚。

メニュー「固定120枚の画像確認盤面」から既存の対戦画面の配置・画像描画を使って確認できる。バトル場・ベンチを順番に入れ替え、手札・トラッシュ・デッキ一覧にも同じ表示処理を使う。画像確認専用であり対戦操作は無効。固定デッキの公式効果・対戦接続は未完了のままで、試験対戦と保存データを変更しない。既存の試験対戦中でも、同じresolverは未確定カードの画像だけを暫定プレビューとして返す。

`fixed-deck-preview-bindings.json`は表示専用の45件。`preview.officialCardId`は画像の参照IDで、`adoptedOfficialCardId`は全件null。複数候補からの代表表示は正式採用版を意味せず、`resolve()`と正式画像監査には昇格しない。ID指定時は既存台帳のID・名前・提示された印刷版条件が一致する画像だけを返し、不明IDや矛盾時は名前プレビューに逃がさない。

名称差異は「たけしのスカウト → タケシのスカウト（50605）」「ロケット団のエネルギー → ロケット団エネルギー（49458）」の表示専用対応。保存済み公式検索候補に基づき詳細2件を追加取得・再解析した。元デッキ名は変更しない。

基本炎・超・悪エネルギーは保存済み公式詳細（49460・49463・49465）の名前・ID・セット・画像URLを再検証。番号欄は空のままnullを保持し、正式台帳93件には追加せず、暫定プレビューだけを許可する。元のHOLD証跡も変更しない。
